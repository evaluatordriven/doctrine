# Mandate skeleton

**Not authority. Not a fixture. Not a record.** A starting shape for the Principal-authored mandate
Contracts §1.7 and C20 require. Fill it in the Principal's words. Do not copy values from this file
into a job and call them ratified.

The packet key this fills, when the job is scored, is `mandate_ref`:

- `mandate_ref.doc` — the name of the filled mandate
- `mandate_ref.version` — the version in force

Do not invent a second name for that pair.
